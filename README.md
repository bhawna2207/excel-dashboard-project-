# excel-dashboard-project- Hospitality Analysis Project 
Analyzed hotel booking data to calculate Total Revenue, Total Bookings, Occupancy Rate, Cancellation Rate, and Utilized Capacity.
Cleaned and transformed data using Excel and Power Query, including handling missing values and duplicates.
Performed weekday vs. weekend, state-wise, hotel-wise, room-class, and booking-status analysis.
Analyzed Checked Out, Cancelled, and No Show bookings and identified revenue and booking trends.
